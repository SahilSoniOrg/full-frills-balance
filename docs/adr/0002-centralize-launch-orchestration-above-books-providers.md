# Centralize launch orchestration above books providers

The root launch coordinator is the canonical owner of Device recovery, Workplace discovery, launch resolution, splash completion, route guarding, and interactive Workplace transitions. A valid blocking Setup draft takes precedence and resolves to `setup(journeyId)`; otherwise the pure resolver returns Device setup, Workplace setup, picker, or the exact `open(workplaceId)` target. Optional Setup drafts never block normal launch. Books-only providers mount only for `open`, and `WorkplaceProvider` receives the validated ID without discovering or creating a Workplace. The separate Setup Coordinator owns slice sequencing and returns typed terminal outcomes to launch; launch never interprets individual setup fields or steps.
