Before: Planned payments appeared as a flat list without month totals or inline overdue settlement. After: add a currency-aware monthly summary and day strip, then group obligations into Overdue, This week, Later this month, Next month, Later, and a collapsed Paused / Ended section.

Every overdue row has its own Record action. It calls the existing record service with the saved occurrence amount and currency, shows busy and inline error states, and blocks duplicate submits. Recording leaves the row through the live update without opening its detail page. Outgoing amounts stay neutral; incoming amounts use the income color and a plus sign. Paused schedules do not project dates, completed schedules retain outstanding occurrences, and unknown directions are excluded from totals. Monetary values and accessible labels respect privacy; large text keeps amounts intact.

Validation: independent typecheck; list/row tests for disclosure, privacy and empty states; inline-record hook tests for locking, saved edits, failures and workplace changes. Recorded full-stack verification passed `bun run verify` with 477 suites / 3,010 tests, architecture/privacy checks, both typechecks, coverage and lint (one existing journal-suggestions warning); see [the exact verification record](https://github.com/SahilSoniOrg/full-frills-balance/blob/codex/commitments-redesign-planned-detail/docs/audits/commitments-redesign-2026-10-04/VERIFICATION.md).
