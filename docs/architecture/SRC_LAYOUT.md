# Source Layout

Where things live under `src/`. Check this before guessing a path: paths like `src/screens`, `src/models`, or `src/app` do not exist. Persistence ownership is in [REPOSITORY_MAP.md](REPOSITORY_MAP.md).

| Folder           | What lives here                                                                                                                                                                                                                           |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `features/`      | Screen-level features, one folder per area: `accounts`, `app`, `audit`, `budget`, `commitments`, `dashboard`, `dev`, `hub`, `journal`, `legal`, `navigation`, `people`, `planned-payments`, `reports`, `reports-v2`, `settings`, `setup`. |
| `components/`    | Shared UI grouped by kind: `core`, `layout`, `forms`, `filters`, `overlays`, `charts`, `shared`, plus per-area folders.                                                                                                                   |
| `design-system/` | Layout primitives (`Stack`, `Inline`, `Box`, `Page`, `SafeArea`) and design helpers. Use these before writing new layout.                                                                                                                 |
| `domain/`        | Business rules grouped by area: `accounting`, `accounts`, `budget`, `journal`, `money`, `people`, `transaction-intelligence`, and others. No React imports.                                                                               |
| `services/`      | Orchestration and side effects, grouped by area: `accounting`, `journal`, `reports`, `sms`, `import`, `setup`, and others.                                                                                                                |
| `data/`          | Persistence: `database/` (schema, migrations, adapters), `models/` (WatermelonDB models), `repositories/`, `cache/`, `storage/`.                                                                                                          |
| `navigation/`    | Route manifest, primary navigation, and route presentation helpers.                                                                                                                                                                       |
| `contexts/`      | React contexts: `WorkplaceContext`, `PrivacyScope`, `UIContext`, `SharingContext`, `app-shell/`.                                                                                                                                          |
| `hooks/`         | Shared React hooks such as `useAccounts`, `useTheme`, `useDateRangeFilter`.                                                                                                                                                               |
| `constants/`     | App config, design tokens, copy (`copy/`), and per-area constants.                                                                                                                                                                        |
| `types/`         | Shared TypeScript types: domain models, read models, import contracts, ids, enums.                                                                                                                                                        |
| `utils/`         | Small pure helpers: formatting, validation, errors, concurrency, serialization.                                                                                                                                                           |
| `presentation/`  | Mappers that turn domain data into view models (`mappers/`).                                                                                                                                                                              |
| `mocks/`         | Module mocks for tests.                                                                                                                                                                                                                   |
| `testing/`       | Test fixtures and E2E harness helpers.                                                                                                                                                                                                    |
| `__tests__/`     | Cross-cutting integration tests. Most unit tests sit next to their source in a `__tests__/` folder.                                                                                                                                       |
